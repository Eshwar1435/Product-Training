# Product-Training

This repository contains a Java console-based ToDo List application under `/ToDoList`.

## Project Structure

- `/ToDoList/src/App.java` - application entry point and menu flow
- `/ToDoList/src/Customer.java` - customer model
- `/ToDoList/src/Task.java` - task model

## How to Run

From the `ToDoList` folder, compile and run:

```bash
javac src/*.java
java -cp src App
```
